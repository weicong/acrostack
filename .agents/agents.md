# AcroStack (ABP + React Classroom) — Agent Guidelines

> Full project reference: [`AGENTS.md`](../AGENTS.md)

## Architecture

ABP single-layer (`app-nolayer`) template: one C# host project + one React SPA. Multi-tenancy enabled.

- `main/AcroStack/` — ASP.NET Core host (.NET 10, ABP 10.4, SQLite, OpenIddict)
- `react/` — React 19 SPA (Vite+, TanStack Router/Query/Form, Fluent UI v9, Kubb, OIDC)

## Backend Commands

```bash
dotnet build                                              # Build solution
dotnet run --project main/AcroStack                       # Run API (https://localhost:44320)
dotnet run --project main/AcroStack --migrate-database    # Migrations + seed
pwsh migrate-database.ps1                                 # Same via script

# EF Core migrations (from repo root)
dotnet ef migrations add <Name> --project main/AcroStack --startup-project main/AcroStack
dotnet ef database update --project main/AcroStack --startup-project main/AcroStack
```

## Frontend Commands

Uses **Vite+** (`vp` CLI), package manager is pnpm:

```bash
vp install            # Install deps (run after pulling)
vp dev                # Dev server (http://localhost:5173)
vp check --fix        # Format + lint + typecheck
vp run generate-api   # Kubb: regenerate API client from Swagger (backend must be running)
```

Backend must be running before `generate-api`.

## Key Conventions

- **Mapperly** (not AutoMapper) for object mapping — mappers in `main/AcroStack/ObjectMapping/`, extend `MapperBase<TSource, TDest>` with `[Mapper(RequiredMappingStrategy = RequiredMappingStrategy.Target)]`
- **Generic repositories only** — no custom repository interfaces; use `IRepository<T, TKey>` directly
- **Feature folders** in `main/AcroStack/Services/` and `main/AcroStack/Entities/`
- **Auto API controllers** — ABP exposes app services as REST automatically; only `HomeController` is hand-written
- `react/src/api/` is auto-generated by Kubb — never edit manually
- Path alias: `@` → `./src` in the React app
- SQLite DB at `main/AcroStack/AcroStack.db`

## Development Flow

1. Start backend: `dotnet run --project main/AcroStack`
2. In `react/`: `vp install && vp dev`
3. After changing backend API: `vp run generate-api`
4. After adding/modifying an entity: add EF migration, then migrate database
5. Before committing: `vp check` in `react/`
