## 技术点：`vp lint` 的 tsgolint 绕法（不存在 `--config` 参数）

`vp lint` 在本沙箱必报 `os error 231`（tsgolint 管道耗尽）。
`vp lint --help` 虽有 `--type-aware` / `--type-check`，但**没有反向的 `--no-type-aware`**；
`vp --help` 也没有全局 `--config`，所以早前设想的「临时 `probe.config.ts`」走不通。

可行做法：临时把根 `vite.config.ts` 的 `lint.options` 改成
`{ typeAware: false, typeCheck: false }` → 跑 `vp lint` → **立刻改回**。
本次 41 文件 / 129 规则 / 0 问题。改回后用 `git diff vite.config.ts` 为空自证已还原。
